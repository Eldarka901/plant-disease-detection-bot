# Plant Disease Detection Bot 🌱

A CNN-based plant disease detection system integrated with a Telegram bot.

## Overview

This project uses a Convolutional Neural Network (CNN) to identify plant diseases from images. The trained model is integrated into a Telegram bot that allows users to upload plant images and receive predictions.

## Features

- Plant disease classification using CNN
- Approximately 90% model accuracy
- Telegram bot integration
- Confidence score for predictions
- User feedback collection
- Healthy / diseased plant detection mode

## Dataset

The model was trained using the PlantVillage dataset and additional plant images collected from parks in Almaty.

## Technologies

- Python
- TensorFlow / Keras
- CNN
- Telegram Bot API

## Results

The model achieved approximately **90% accuracy** on the evaluation data.

## Future Development
